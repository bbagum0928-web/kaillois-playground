# 카이와 놀이터 (Netlify 배포용)

혼자서 하는 4가지 놀이(별똥별·행운 상자·던전 글자 모험·풍선 버티기)로 로제 카이와의 놀이 4요소를 체험하고, 점수를 선생님 화면에 모으는 웹앱입니다.

## 폴더 구성
- `index.html` 학생 화면 + 선생님 화면(주소 뒤에 `#teacher`)
- `netlify/functions/scores.mjs` 점수 저장 함수 (Netlify Blobs 사용)
- `vendor/qrcode.js` QR 코드 생성 라이브러리
- `package.json`, `netlify.toml` 설정 파일

## 배포 방법 A: GitHub 연결 (가장 추천)
1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 올리지 않아요).
2. Netlify > Add new site > Import an existing project > 저장소 선택.
3. 설정은 `netlify.toml`에 있어서 그대로 Deploy 하면 됩니다.
4. 배포가 끝나면 나온 주소(`https://○○○.netlify.app`)가 학생 주소입니다.

## 배포 방법 B: 명령어(CLI)
```
npm install -g netlify-cli
npm install
netlify login
netlify deploy --prod
```

## 주의: 드래그 앤 드롭 배포
폴더를 끌어다 놓는 방식은 함수(점수 저장)와 패키지 설치가 제대로 되지 않을 수 있습니다. 점수 저장을 쓰려면 A 또는 B 방법을 쓰세요. 드래그 앤 드롭으로 올려도 게임은 되지만, 점수는 서버에 저장되지 않고 학생 화면의 결과 코드로만 모을 수 있습니다.

## 수업 날 사용법
1. 선생님 폰/PC에서 `주소/#teacher` 를 엽니다.
2. 수업 코드(4글자)를 정하고 [적용]을 누르면 QR이 나옵니다. 화면에 띄워 학생이 찍게 하세요.
3. 학생은 별명만 정하고 놀이를 합니다 (번호 입력 없음).
4. 학생이 끝나면 점수가 순위판에 3초마다 자동으로 나타납니다.
5. [표로 복사]로 스프레드시트에 붙여 넣을 수 있습니다.

## 선택: 삭제용 비밀번호
Netlify > Site configuration > Environment variables에 `TEACHER_PIN`을 만들면, 순위판에서 지우기를 할 때 선생님 화면의 비밀번호 칸에 같은 값을 넣어야 합니다. 만들지 않으면 누구나 지울 수 있어요(수업 코드를 아는 사람만).

## 점수를 못 보낼 때
네트워크가 불안하면 학생 화면에 17자리 결과 코드가 나옵니다. 선생님 화면의 [결과 코드로 직접 추가]에 입력하면 됩니다.

## 참고
- 점수 저장은 로컬에서 가짜 저장소로만 테스트했고, 실제 Netlify에서는 아직 확인하지 않았습니다. 배포 후 폰 한 대로 한 번 끝까지 해 보세요.
- 한 수업 코드에 최대 150명까지 저장됩니다.
